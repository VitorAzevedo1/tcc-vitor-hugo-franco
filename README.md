## Sobre o projeto

Plataforma digital multiplataforma para organização, visualização e compartilhamento seguro de informações pessoais de saúde da pessoa idosa. O sistema permite o cadastro de medicamentos, alergias, contatos médicos, histórico de consultas e observações pessoais, além de compartilhamento controlado com familiares autorizados e cuidadores.

## Tecnologias

- **Backend:** Java 21 + Spring Boot 3.4
- **Frontend:** React Native (em desenvolvimento)
- **Banco de dados:** MySQL (produção) / H2 (desenvolvimento)
- **Comunicação:** API REST
- **Migrations:** Flyway
- **Build:** Maven
